# Мастер презентаций

Генерация HTML-презентаций из анкеты через LLM. Потребляет сервис **SBE LLM Center**
(`sbe-llm`) через мост `window.SBE`. Данные хранятся отдельно от монолита:
`yourbase/sbe_presentations/`.

## Возможности

- Анкета + мозговой штурм (LLM задаёт уточняющие вопросы).
- Генерация структуры по дизайн-скилу и шаблонам оформления.
- WYSIWYG-редактор слайдов (title, section, bullets, cards, table, photo, final).
- Иллюстрации, QR-код (vCard), предпросмотр, экспорт в HTML/PDF.
- Черновики, кэш HTML, извлечение шаблона из примера презентации.
- UI на русском языке.

## Настройка

1. Установите и включите **SBE LLM Center** (`sbe-llm`), задайте в нём API-ключ.
2. В настройках «Мастер презентаций» укажите модели LLM (до 5), модель по умолчанию
   и шаблон оформления по умолчанию.

## Для разработчиков

- Промты и модель живут в потребителе (`src/services/llm-consumer.ts`), центр о них не знает.
- Сервис LLM получается лениво: `getService('sbe-llm')` при первом использовании.
- Данные: `yourbase/sbe_presentations/` (БД, `templates/`, `rules/`, `pics/`).
